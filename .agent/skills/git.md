# Git Workflow

## Commit Messages

- Write single-line commit messages in English.
- Use natural, descriptive, imperative sentences (e.g., `Update Tailwind configuration for post cards`).
- Do NOT use Conventional Commits prefixes (`feat:`, `fix:`, `chore:`, etc.).
- **New blog posts:** use `New post: <post-title>` keeping the post's original title (e.g., `New post: Vivendo no terminal: tmux + neovim`).

## Commit Scope

- Keep commits atomic and separated by topic (e.g., do not mix blog posts/assets with tooling or configuration changes in the same commit).

## Branching

- Direct commits to `main` (or `master`) are acceptable for this solo/small project setup unless otherwise specified.
