# General Context

## Project Overview

This repository (`lpsouza.github.io`) is the personal website, portfolio, and blog of the user. It is hosted on GitHub Pages using Jekyll and styled with Tailwind CSS.

## Goals

- Present technical articles and portfolio content clearly.
- Maintain a high-performance, lightweight frontend.
- Ensure easy maintenance by using standard Jekyll patterns and markdownlint compliance.

## Team Structure

We are operating under the "AI Teams" model:

- **User**: The Product Owner / Final Approver.
- **AI Agents**: The Development and Editorial Team (Frontend Developer, Tech Lead, Editorial Reviewer).
